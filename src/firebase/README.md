# Firebase Services

This directory contains Firebase configuration and service layers for Firestore operations.

## Structure

```
firebase/
├── config.js              # Firebase initialization and configuration
├── services/
│   ├── tasksService.js    # Task CRUD operations
│   ├── routinesService.js # Routine CRUD operations
│   └── notesService.js    # Note CRUD operations
└── index.js               # Main export file
```

## Usage

### Basic Import

```javascript
import { db } from '../firebase/config';
import { getAllTasks, createTask, subscribeToTasks } from '../firebase/services/tasksService';
```

### Tasks Service

```javascript
// Get all tasks
const tasks = await getAllTasks();

// Create a task
const taskId = await createTask({
  title: "New Task",
  completed: false,
  isUrgent: false,
  date: new Date(),
  tags: ["work"],
  subtasks: []
});

// Update a task
await updateTask(taskId, { completed: true });

// Delete a task
await deleteTask(taskId);

// Subscribe to real-time updates
const unsubscribe = subscribeToTasks((tasks) => {
  console.log('Tasks updated:', tasks);
});

// Don't forget to unsubscribe when done
unsubscribe();
```

### Routines Service

```javascript
import { getAllRoutines, createRoutine, updateRoutine } from '../firebase/services/routinesService';

// Get all routines
const routines = await getAllRoutines();

// Create a routine
const routineId = await createRoutine({
  name: "Morning Workout",
  startTime: "6:00 AM",
  endTime: "7:00 AM",
  days: ["Mon", "Wed", "Fri"],
  enabled: true
});
```

### Notes Service

```javascript
import { getAllNotes, createNote, archiveNote } from '../firebase/services/notesService';

// Get all notes (excluding archived and deleted)
const notes = await getAllNotes();

// Get all notes including archived
const allNotes = await getAllNotes(true, false);

// Create a note
const noteId = await createNote({
  title: "Meeting Notes",
  content: "Discussed project timelines...",
  tag: ["Work"],
  archived: false,
  deleted: false
});

// Archive a note
await archiveNote(noteId, true);
```

## Data Structure

### Task Document

```javascript
{
  id: "document-id",           // Auto-generated by Firestore
  title: "string",
  completed: boolean,
  isUrgent: boolean,
  date: Timestamp,             // Firestore Timestamp
  tags: ["tag1", "tag2"],      // Array of tag IDs or strings
  subtasks: [                  // Array of subtask objects
    {
      id: "subtask-id",
      title: "string",
      completed: boolean,
      subtasks: []              // Nested subtasks
    }
  ],
  createdAt: Timestamp,
  updatedAt: Timestamp
}
```

### Routine Document

```javascript
{
  id: "document-id",
  name: "string",
  startTime: "string",         // e.g., "6:00 AM"
  endTime: "string",           // e.g., "7:00 AM"
  days: ["Mon", "Wed", "Fri"], // Array of day abbreviations
  enabled: boolean,
  createdAt: Timestamp,
  updatedAt: Timestamp
}
```

### Note Document

```javascript
{
  id: "document-id",
  title: "string",
  content: "string",
  tag: ["tag1", "tag2"],       // Array of tag strings
  archived: boolean,
  deleted: boolean,             // Soft delete flag
  createdAt: Timestamp,
  updatedAt: Timestamp
}
```

## Real-time Subscriptions

All services provide subscription functions for real-time updates:

```javascript
// Tasks
const unsubscribeTasks = subscribeToTasks((tasks, error) => {
  if (error) {
    console.error('Error:', error);
    return;
  }
  // Update your state with tasks
  setTasks(tasks);
});

// Routines
const unsubscribeRoutines = subscribeToRoutines((routines, error) => {
  // Handle updates
});

// Notes
const unsubscribeNotes = subscribeToNotes((notes, error) => {
  // Handle updates
}, includeArchived, includeDeleted);

// Cleanup
useEffect(() => {
  return () => {
    unsubscribeTasks();
    unsubscribeRoutines();
    unsubscribeNotes();
  };
}, []);
```

## Error Handling

All service functions throw errors that should be caught:

```javascript
try {
  const tasks = await getAllTasks();
} catch (error) {
  console.error('Failed to fetch tasks:', error);
  // Show error to user
}
```

## Migration from Realm

When migrating from Realm to Firebase:

1. **Data Migration**: Write a script to export Realm data and import to Firestore
2. **Replace Service Calls**: Update components to use Firebase services instead of Realm
3. **Update State Management**: Use Firebase subscriptions for real-time updates
4. **Remove Realm**: Once migration is complete, remove Realm dependencies

## Configuration

Make sure to configure Firebase in `config.js` with your Firebase project credentials. See `FIREBASE_SETUP.md` in the root directory for setup instructions.
